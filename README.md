# NetSage AI

AI-Assisted Network Troubleshooting Helper
with Human Review.

## Objective

Help junior network engineers identify
network faults using symptoms, topology
information and Cisco show-command outputs.

## Technologies

- Python
- Gemini API
- Streamlit
- Pandas
- SQLite
- Plotly
- Cisco Packet Tracer

## Main Features

- Network fault diagnosis
- Evidence-based troubleshooting
- Python rule checker
- AI-assisted recommendations
- Human review system
- Analytics dashboard
